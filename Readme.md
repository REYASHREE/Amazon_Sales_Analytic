# Amazon Sales Analytics

**Author:** REYASHREE PAUL  
**Tools:** SQL, Python (Pandas), Excel, Power BI  
**Domain:** E-commerce | Sales & Business Analytics

## Project Overview

An end-to-end analysis of Amazon sales data to uncover revenue trends, product performance, regional patterns, and key business insights. The project combines SQL-based data analysis with Excel and Power BI dashboards to transform raw sales data into actionable insights.

## Objectives

- Analyze revenue and order performance
- Identify top-performing products and categories
- Evaluate regional and time-based sales trends
- Identify sales patterns and performance gaps
- Build interactive dashboards for business decision-making
- Translate data findings into actionable business insights

## Key Skills Demonstrated

- Data Cleaning & Transformation
- SQL Querying & Aggregation
- Exploratory Data Analysis
- KPI & Trend Analysis
- Excel Dashboarding
- Power BI Visualization
- Business Insight Generation

## Workflow

Raw Data → Data Cleaning → SQL Analysis → EDA → Dashboard → Business Insights
