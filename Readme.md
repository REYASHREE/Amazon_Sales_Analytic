# Amazon Sales Analytics

An end-to-end e-commerce sales analytics project focused on understanding Amazon sales performance, revenue trends, order fulfillment, delivery performance, and operational revenue risk.

The project combines **SQL, Excel, Power BI, and Python (Pandas)** to transform raw sales data into actionable business insights.

# Business Problem

E-commerce businesses generate large volumes of order and revenue data, but raw data alone does not explain:

- How sales are changing over time
- Which order statuses contribute most to revenue
- How efficiently orders are being delivered
- How much revenue is currently at risk
- Where fulfillment and post-delivery problems occur
- Which operational issues require attention

This project analyzes Amazon sales data to identify these patterns and translate them into business insights.
